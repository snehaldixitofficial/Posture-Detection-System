# MultiPosture reference dataset

`multiposture.csv` is an unchanged copy of `data.csv` from the MultiPosture
dataset by David Carneros Prado, Luis Cabañero Gómez, Jesus Fontecha, Ramon
Hervas, Iván González Díaz, and Esperanza Johnson (2024).

Source: https://doi.org/10.5281/zenodo.14230872
License: Creative Commons Attribution 4.0 International (CC BY 4.0).
License text: https://creativecommons.org/licenses/by/4.0/
Publisher MD5: `7efbc94d653acf32eefecec3ff26d6c6`.
Saved publisher metadata: `multiposture_metadata.json`.

This reference dataset was audited, but was not used to train or evaluate the
deployed posture models. Its measurements and labels differ from the recorded
head-and-shoulder pilot. See `docs/DATASET_ASSESSMENT.md` in the repository.
