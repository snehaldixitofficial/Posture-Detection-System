Test results

For this pilot, one person recorded eight videos in four postures. The first set of recordings was used for training (962 frames); a separate set was used for testing (968 frames). The models in the demo are the ones evaluated below.

Results on the separate test recordings
Model Accuracy Macro F1 Validation F1
Random Forest 98.35% 0.9835 0.9807
SVM (RBF) 95.14% 0.9510 0.9807
XGBoost 98.86% 0.9886 0.9494

This study has only one participant, so these numbers do not tell us how well the models will work for other people.

How was the model selected?

Random Forest and SVM tied on validation macro F1. Random Forest was selected using the experiment's documented tie order. XGBoost scored highest on the separate test videos. The original three-state rules scored 0.9756 macro F1; the separately evaluated four-state directional rule extension scored 0.9762.

What did the models get wrong?

All errors on the test recordings were upright frames classified as Slouch: 16 for Random Forest, 47 for SVM and 11 for XGBoost, out of 242 upright frames. All three models correctly classified the 242 test frames in each of the other classes. Frames close together in a video are correlated; they are not separate participants.

About the project

This project compares three machine-learning models for detecting posture from a regular webcam. It uses the face and shoulders, so the rest of your body does not need to be in the frame.

How it works

  1. MediaPipe finds points on the nose, eyes, ears and shoulders.
  2. The code checks that seven required points are visible, then calculates 21 measurements: distances, angles, offsets and estimated depth differences.
  3. The same measurements go to each trained model. Random Forest combines tree probabilities, SVM uses pairwise votes, and XGBoost adds tree scores.
  4. The selected model's answer appears on the camera view. The comparison panel shows the other models' answers.
What does this project contribute?

The contribution is the complete, auditable pipeline: head-and-shoulder measurements, quality checks that preserve slouch examples, testing on separate videos, and browser predictions checked against Python. The three classifiers are established algorithms. More participants are needed to evaluate whether the approach generalizes.

Why can I only calibrate the simple rules?

The rules compare two measurements with your upright reference. The trained models use a fixed set of inputs; changing those inputs through calibration would make them different from the training data.
